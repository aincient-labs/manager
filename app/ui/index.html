    Share your site with the world

    Atelier can turn your website into a folder of plain files you can put on any web host — many are free, like Netlify, Cloudflare Pages, or GitHub Pages. Your Atelier stays private here; this just makes a copy to publish.

    Your website needs to be running before you can publish it.

    Now put it online

    What Atelier made is ordinary web files, so any host will take them. Here are three that are free to start with — easiest first.

    • Netlify Drop Drag the folder onto the page. Nothing to set up, and your site is live in seconds.
    • Cloudflare Pages Upload the folder from your dashboard. Free custom domains and certificates.
    • GitHub Pages, Vercel, or a host you already use Start from our ready-made template: copy it, put your export in site/, push.

    Each button opens the host in your browser and reveals your export folder, ready to drag.

    Experimental features

    Off unless you turn it on. These are for testers.

    This site runs the experimental engine. Turn on experimental features to see it, lock the site down, or remove the engine.

    What you are turning on. The engine is a helper that runs next to your site and can start, stop and lock it. To do that it holds the server's Docker socket, which is full control (root) of that server. It is new and still being tested by security reviewers. Use it on a test site, not one you depend on.
